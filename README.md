## 📌 Sobre o Projeto

O **projeto-banco-NodeJS** é um sistema de backend bancário projetado para gerenciar contas de usuários, operações financeiras (como depósitos, saques e transferências) e consultas de saldo e extrato com segurança, performance e simplicidade.

---

## 🚀 Como Iniciar o Projeto

### 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (Versão 16.x ou superior recomendada)
- [Git](https://git-scm.com/)
- Gerenciador de pacotes `npm` ou `yarn`

<div align="center">
  <img src="https://raw.githubusercontent.com/devicons/devicon/master/icons/nodejs/nodejs-original-wordmark.svg" alt="NodeJS Logo" width="600" height="230" />
</div>

### 🔧 Passo a Passo

---

1. **Clone o repositório:**
```bash
git clone https://github.com/kauedavi/projeto-banco-NodeJS.git

```

2. **Acesse o diretório do projeto:**
```bash
cd projeto-banco-NodeJS

```

3. **Instale as dependências:**
```bash
npm install

```


4. **Configure as Variáveis de Ambiente:**
Crie um arquivo `.env` na raiz do projeto com base no modelo `.env.example` (caso existente):
```env
PORT=3000

```


5. **Execute a aplicação:**
* Modo de Desenvolvimento:
```bash
npm run dev

```


* Modo de Produção:
```bash
npm start

```


6. **Testar as Rotas:**
A API estará rodando por padrão em `http://localhost:3000`.
